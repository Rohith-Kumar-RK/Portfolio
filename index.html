Projects

Projects

Selected projects spanning Machine Learning, Deep Learning, Generative AI, LLMs, Computer Vision, and AI agents.

Adversarial Research Council -- Multi-Agent Self-Correcting Research System

Built a 5-agent LangGraph system (Scout, Analyst, Skeptic, Memory Keeper, Synthesizer) where research claims must survive adversarial challenge before publishing, instead of trusting single-pass LLM output.

Designed a Skeptic agent that actively searches for counter-evidence against every claim, driving up to 3 rounds of challenge-and-revise, with surviving claims scored 0–1 for confidence.

Implemented Neo4j graph memory that cross-checks new findings against past research sessions and auto-flags contradictions over time.

Built a live Streamlit dashboard streaming the agent debate in real time, backed by Qdrant vector memory for traceable, source-tagged evidence retrieval.

Deep Learning-Based End-to-End Speech Enhancement, Packet Loss Concealment, and Automatic Speech Recognition

Developed an end-to-end speech enhancement and packet loss concealment system using Wavelet Denoising, Wiener and Kalman Filtering, and a CUDA-accelerated Conditional GAN (U-Net + PatchGAN), improving reconstructed audio SNR from -31 dB to 12.18 dB.

Integrated Wav2Vec 2.0 (HuggingFace) for speech-to-text transcription and evaluated performance using BLEU 87%, WER 8.0%, and CER 7.8%.

ARNA - Agricultural Real Time Neural Advisor with Potato Crop Disease Detection and Fertilizer Recommendation Bot

Developed an AI-powered potato disease detection system using CNN and OpenCV for image preprocessing, classifying leaves into Early Blight, Late Blight, and Normal categories, along with a Random Forest-based fertilizer recommendation system.

Built an agricultural RAG chatbot using FAISS, Sentence Transformers, and Gemini Flash to retrieve relevant knowledge and generate context-grounded responses, evaluated the pipeline using RAGAS.

Optimized and deployed the application using ONNX and quantization, with a FastAPI backend, React.js frontend, Docker containerization, and Git/GitHub for version control.

Explainable AI in Supervised Learning (Finance)

Researched multi-horizon stock price prediction using Machine Learning and Deep Learning models for forecasting across multiple time horizons.

Applied SHAP, LIME, and Explainable Boosting Machines (EBM) to interpret model predictions and identify influential features.

Used counterfactual analysis to examine how changes in input features could influence predicted stock prices and improve prediction interpretability.

A Decision Making System Based on Remote Sensing for Tomato Crop Cultivation Using Deep Learning

Developed a GIS and CNN-LSTM-based Decision-Making System for tomato cultivation in Madanapalli, integrating Sentinel-2 satellite data, NDVI, soil moisture, and ground-truth data.

Processed multi-year remote sensing data using QGIS to identify optimal planting periods, supporting precision agriculture, crop-loss reduction, and improved yield efficiency.

Remote Sensing Based Tomato Crop Yield and Price Prediction using ML/DL

Integrated Sentinel-2 remote sensing data, QGIS, Google Earth Engine (GEE), and ground-truth data to classify tomato crops, calculate cultivated area, and generate NDVI time-series data (2014–2023).

Developed a CNN-GRU hybrid model to extract spatial-temporal features from NDVI time-series data and predict tomato crop yield per hectare.

Developed a Random Forest ensemble model, fine-tuned using Grid Search, to predict tomato market prices based on predicted crop yield and historical price data.
